# Neon Rally · 霓虹网球

零构建步骤的 3D 街机网球游戏。游戏内容全部在 `dist/`，Three.js 0.160.1 已随源码附带；运行时无需访问第三方 CDN。

## 在线试玩

GitHub Pages 使用仓库根目录的 `index.html`，它包含全部样式和脚本。重新发布前运行 `npm run build:pages`，并将更新后的根入口一同上传。

## 运行

在本目录运行 `npm start`，然后打开 <http://127.0.0.1:4173/>。需要 Python 3；Node.js 用于执行测试。

也可以直接用浏览器打开 `dist/play-offline.html`，无需启动服务器或联网。修改源码后运行 `npm run build:offline` 重新生成离线版。

## 操作

| 按键 | 操作 |
| --- | --- |
| ← / → 或 A / D | 左右移动 |
| 空格 | 发球、普通挥拍 |
| Q / E | 角色专属球技，直接完成挥拍 |
| R | 满能量大招 |
| Shift + 方向键 | 滑步救球 |
| Esc | 暂停、继续 |

两名角色各有三种专属球技。普通回球积攒能量，精准回球奖励更多；技能消耗能量并进入冷却。技能需要到位并在接球窗口内出手。先得 7 分且领先 2 分获胜；每分轮换发球。AI 遵守相同技能消耗与冷却，提供三个难度。浏览器失焦自动暂停。窄屏提供触控移动和挥拍按钮，也可点击技能栏。

## 验证

运行 `npm test`。测试覆盖发球、球网、反弹、出界、技能、资源冷却、滑步、AI、计分和不同帧率下的模拟一致性。

## 文件

- `dist/engine.js`：独立物理与比赛状态。
- `dist/scene.js`：3D 球场、人物动作、球路效果。
- `dist/app.js`：界面、输入、音效、暂停与结算。
- `tests/engine.test.mjs`：比赛逻辑回归测试。

角色、招式及场景为本项目原创。Three.js 采用 MIT 许可证，见 `dist/vendor/THREE-LICENSE.txt`。
